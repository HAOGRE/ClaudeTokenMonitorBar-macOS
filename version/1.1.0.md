## 构建检查清单

### 1. Scheme 选择
- [ ] 使用 **CTMB AppStore** scheme
- [ ] 确认 PRODUCT_NAME = "AITokenMonitor"
- [ ] 确认 Bundle ID = "com.haogre.claudetokenmonitor"

### 2. 版本号确认
编辑 `project.pbxproj`：
```
MARKETING_VERSION = 1.1.0;
CURRENT_PROJECT_VERSION = 8;
```

### 3. 归档构建 (Archive)
```bash
xcodebuild -project ClaudeMonitor.xcodeproj \
  -scheme "CTMB AppStore" \
  -configuration Release \
  -destination 'platform=macOS' \
  archive \
  -archivePath "build/AITokenMonitor-v1.1.0.xcarchive"
```

### 4. 导出并验证
- [ ] 使用 Xcode Organizer 导出
- [ ] 上传到 App Store Connect
- [ ] 通过 App Store 审核前的自动验证

## 提交流程

1. **准备构建**
   - 确认 Scheme: "CTMB AppStore"
   - 确认版本号和 build 号正确

2. **Archive 构建**
   - Product → Archive
   - 等待构建完成

3. **分发 App**
   - 在 Organizer 中选择 Archive
   - 点击 "Distribute App"
   - 选择 "App Store Connect"
   - 选择 "Upload"

4. **App Store Connect**
   - 登录 https://appstoreconnect.apple.com
   - 进入 Apps → AITokenMonitor
   - 选择版本 1.1.0
   - 填写更新说明（复制上方中文/英文）
   - 提交审核
