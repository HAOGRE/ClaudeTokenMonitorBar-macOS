FAQ

Questions, answered

Everything you might want to know before installing CTMB.

Does CTMB send my data anywhere?

No. CTMB reads the local session files Claude Code writes on your Mac — that data never leaves your machine. There is no daemon, no account and no telemetry. The only network request it ever makes is to the official usage endpoint, to read your own account's rate limits, and only when you are already signed in.

Is CTMB free?

Yes. CTMB is free and open source under the MIT license. Download the DMG from GitHub releases, or build it from source.

What's the difference between the GitHub version and the Mac App Store one?

Same app, same features. The GitHub build is free and open source, but you update it yourself and have to clear Gatekeeper on first launch. The Mac App Store build costs $0.99, is sandboxed, updates automatically, and is listed as Usage Monitor for AI Token — App Store rules don't allow a third-party product name in the app's title. Buying it is also the easiest way to support the project.

What do I need to run CTMB?

macOS 14 or later and Claude Code installed. CTMB is a universal binary that runs natively on both Apple Silicon and Intel Macs.

How accurate is the cost estimate?

When a session entry already includes an exact cost, CTMB uses it directly. Otherwise it calculates cost from the official Anthropic pricing table for each model — Fable 5, Opus, Sonnet and Haiku.

Do I need claude-code-usage-monitor?

No. Core token, cost and history tracking works standalone. The official 5-hour and 7-day rate-limit windows appear as an optional enhancement when the claude-code-usage-monitor tool is also running.
