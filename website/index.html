Features

Everything you need. Nothing you don't.

A focused menu bar tool that surfaces exactly what matters about your Claude Code spend.

📊

Live menu bar rates

Double-row input / output token rates while Claude is active, switching to accumulated cost when idle.

🛡️

Official rate limits

The 5-hour token window with a color-coded progress bar and reset countdown, straight from the v4 state protocol.

💰

Accurate cost tracking

Total and today's cost with exact multi-model pricing — Fable 5, Opus, Sonnet and Haiku — down to the token.

📈

30-day trend

A collapsible chart of daily spend, top projects by cost, and your most recent sessions at a glance.

🔒

100% local

Reads local session files only. No network requests, no daemon, no accounts. Your data never leaves the Mac.

🌐

Native & bilingual

Pure Swift + SwiftUI with zero dependencies. Universal binary, English & Chinese, follows your system locale.

Your usage data
never leaves your Mac.

CTMB reads the JSONL session files Claude Code already writes locally, parses them, and renders the result — entirely on-device. There are no servers, no telemetry, and no sign-in.

Optionally, when claude-code-usage-monitor is running, it layers in the official 5-hour rate-limit window too.

1Claude Code writes ~/.claude/projects/*.jsonl
2CTMB parses tokens, computes cost, deduplicates
3Rendered natively in your menu bar — every 5s
