### 顺带修掉的一个真问题：AppStore 构建缺 entitlements

`CODE_SIGN_ENTITLEMENTS` 原先只配在 **Debug** 配置上，AppStore 配置从没引用过 `ClaudeMonitor.entitlements`。结果签出来的包只有 Xcode 由 `ENABLE_APP_SANDBOX` / `ENABLE_USER_SELECTED_FILES` 自动合成的两条权限，缺了：

- `com.apple.security.files.bookmarks.app-scope` —— **security-scoped bookmark 无法持久化**，等于用户每次启动都要重新授权目录
- `com.apple.security.network.client` —— 限额查询的网络请求会被沙盒拦掉
- `temporary-exception…/.claude-monitor/` —— 配套工具的状态文件读不到

线上 1.1.0（`v1.1.0` tag）也是同样的配置，所以这个问题**在已上架版本里就存在**。已在 AppStore 配置补上 `CODE_SIGN_ENTITLEMENTS`，重新归档后 `codesign -d --entitlements -` 验证五条权限齐全。

> 如果想把审核风险压到最低，可以给 AppStore 单独建一份 entitlements，去掉 `temporary-exception` 那条——代价是配套工具的官方限额区块在 App Store 版失效，退化成本地估算。当前保留了完整权限，§4 的 Review Notes 里已写好对应的说明理由。

重打归档：

```bash
cd ClaudeMonitor
rm -rf build DerivedData-AppStore-2.0.0
xcodebuild -project ClaudeMonitor.xcodeproj -scheme "CTMB AppStore" \
  -configuration AppStore -destination 'platform=macOS' \
  -archivePath build/AITokenMonitor-v2.0.0.xcarchive archive
xcodebuild -exportArchive \
  -archivePath build/AITokenMonitor-v2.0.0.xcarchive \
  -exportPath build/AITokenMonitor-v2.0.0-export \
  -exportOptionsPlist export-options-appstore-2.0.0.plist
# 确认产物是 AITokenMonitor.pkg，不是 ClaudeTokenMonitorBar.pkg
```

## 4. App Review Notes

审核机器上没装 Claude Code，直接打开面板是空的——这是本次最大的驳回风险。以下内容整段填进 ASC 的 App Review Information → Notes，并把样本数据 zip 一起附上。

**生成样本数据：**

```bash
python3 scripts/make-review-sample.py review-sample/projects
cd review-sample && zip -r ../review-sample.zip projects
```

脚本会打印这批数据对应的预期总量（当前种子：1308 条、约 103.44M tokens、$136.98），用来和 App 显示的数字对照。已用真实解析器验证过读取结果一致。

**Notes 正文（英文）：**

```
IMPORTANT — this app has no Dock icon and no window. It runs in the menu bar only
(LSUIElement). After launching, please click its icon in the menu bar at the top
right of the screen to open the dashboard.

WHERE THE DATA COMES FROM
The app reads local JSONL session logs that the Claude Code command line tool
writes under the user's home folder (~/.claude/projects). On a Mac where that tool
is not installed there is no data, and the dashboard will legitimately be empty.

HOW TO SEE THE APP WITH DATA
We have attached sample-data.zip for this purpose.
1. Unzip it anywhere, for example to your Desktop. It contains a "projects" folder.
2. Launch the app and click its menu bar icon.
3. The app shows a "Grant Access" panel (a standard NSOpenPanel). Select the
   "projects" folder you just unzipped and click Grant Access.
4. The dashboard will populate. You should see roughly 103M total tokens and about
   $137 of estimated cost, a per-model breakdown, trend cards and an activity heatmap.
The app stores this permission as a macOS security-scoped bookmark, so any folder
you select works — no special setup is required.

ENTITLEMENTS
- com.apple.security.files.bookmarks.app-scope: to remember the folder the user
  granted access to, so we do not prompt on every launch.
- com.apple.security.temporary-exception.files.home-relative-path.read-only
  (/.claude-monitor/): read-only access to an optional status file
  (~/.claude-monitor/state/latest.json) written by a separate open source companion
  tool. If that file is absent the related section simply does not appear. We never
  write to this location.
- com.apple.security.network.client: used only to query the official usage endpoint
  for the signed-in user's own rate limits. No data is sent to our servers; we do
  not operate any server.

NAMING
The app name contains no third-party trademark. Where "Claude" appears inside the
UI it is a factual reference to the model that produced a given usage record, and
to the developer tool whose local logs the app reads.
```

**中文备忘（不填进 ASC，自己核对用）：**

1. 样本数据一定要附。这一步不做，审核员大概率看到空面板然后按 2.1 驳回。
2. MCP / Skill 卡片在审核机器上会是空的——这两项要靠 `~/.claude.json` 和 `~/.claude/skills` 归因，而这两个路径在沙盒里读不到，样本数据也不覆盖。属于正常降级，Notes 里没必要主动提。
3. 5 小时 / 7 天限额窗口需要已登录凭据或配套工具，审核机器上也会缺失。同样是正常降级。
